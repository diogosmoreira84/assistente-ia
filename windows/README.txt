Watch Claude Code and Codex from your phone, answer their permission requests
anywhere, and follow usage limits, activity and daily summaries.

INSTALL (Windows x64)
1. Extract this ZIP and open Install-AssistenteIA.cmd.
2. The installer adds the PhoneBox desktop agent, a private Python runtime and
   the Assistente IA portal for the current user, then opens the portal.
3. Create your account and choose Connect this PC on the Overview page.
4. Sign in to Claude Code and/or Codex on this PC as usual. Their permission
   requests now also reach the portal and your phone.
Start it later from Start menu > Assistente IA.

PHONE (Android)
In the portal, open Downloads and scan the QR code with your phone, install the
app, then open Devices > Show pairing code and scan it from the app. Turn on
"Notify me in the background" to answer requests while the app is closed.

ANOTHER COMPUTER
Install the package there too and run Connect-Portal.cmd with the portal's
Tailscale address and an agent key from Devices.
